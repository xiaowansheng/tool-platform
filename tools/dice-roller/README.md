# Dice Roller (摇色子工具)

3D 拟真摇色子工具与趣味骰子游戏（骰宝、骰子对决），支持多种多面体骰子与逼真碰撞滚动音画效果。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | 娱乐工具 (entertainment-tools) |
| 运行环境 | simple |

## 功能与游戏模式

1. **自由投掷**：
   - 支持多种常用多面体骰子组合：D4、D6、D8、D10、D12、D20、D100。
   - 其中的 D6 (立方体骰子) 采用纯 CSS 3D Cube 技术，支持多个轴向翻转和碰撞着陆效果。
   - 其它多面体骰子采用定制几何矢量 SVG 造型并提供数字滚动闪烁动画。
   - 提供落地点数汇总、平均值统计及完整的投掷历史。

2. **趣味骰宝 (Sic Bo)**：
   - 绿色呢面台盘与经典赌桌投注区：大/小/单/双/豹子。
   - 纯合成 Web Audio rattle 碰撞声效与拟真木杯抖动扣骰动画。
   - 虚拟筹码记录（自动持久化到本地 localStorage），包含筹码输赢和破产补助金奖励。

3. **骰子对决 (Dice Battle)**：
   - 与对手 AI 进行骰子扑克（Dice Poker）式的对决。
   - 双方各摇 5 颗骰子，系统自动判定手牌牌型（五同豹子 > 四条 > 葫芦 > 顺子 > 三条 > 两对 > 一对 > 散牌）。
   - 支持设置押注额度并记录对战成绩表格。
