# IPv6 Subnet Calculator

计算 IPv6 网段信息：前缀、子网掩码、地址总数与范围，支持缩写展开。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | webmaster-tools |
| 子分类 | ip |
| 运行环境 | simple |
