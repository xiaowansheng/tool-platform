# CSS Color Picker

从多种颜色盘中选取颜色并一键复制。

## 功能

- **取色器**: 色相滑块 + 饱和度/明度面板，自由调色
- **格式切换**: HEX / RGB / HSL / RGBA / HSLA 随意切换
- **CSS 命名色**: 按色系分组的 140+ 常用 CSS 命名色
- **Flat UI**: 经典 Flat UI 配色方案
- **语义色**: Success、Warning、Error、Info 等 UI 语义色
- **Tailwind**: Tailwind CSS 标准色板
- **一键复制**: 点击色块按所选格式复制颜色值
