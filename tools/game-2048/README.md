# 2048 Game (2048 经典合并游戏)

经典 2048 数字拼图游戏，支持 3x3、4x4、5x5 多种棋盘，具备丝滑的滑动合体动画、音效及键盘和触屏滑动操作。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | 娱乐工具 (entertainment-tools) |
| 运行环境 | simple |

## 功能特点

1. **多种尺寸选择**：3x3 (极速模式)、4x4 (经典挑战)、5x5 (轻松游玩)。
2. **多终端适配**：支持键盘方向键与 WASD 键控制，同时集成触控滑动判断（Swipe Gestures）适用于手机或平板等触屏设备。
3. **音效支持**：纯合成 Web Audio 产生的移动破风声、合成叠加音效及结束悲伤音效。
4. **历史最高分**：独立储存每个规格的最佳记录到 localStorage 中。
