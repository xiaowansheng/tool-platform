# JSON Formatter

格式化、压缩、校验并以树形视图展示 JSON 文本。

## 功能

- **格式化** — 可配置 2/4/8 空格缩进
- **压缩** — 去除空白字符
- **自动格式化** — 输入即格式化，无需手动点击
- **排序键** — 按字母顺序排列对象键
- **树形视图** — 交互式可折叠树，点击键名复制 JSON 路径
- **大小对比** — 输入/输出的字符数和字节数
- **精确报错** — 显示错误行号和列号
- **剪贴板** — 粘贴输入、复制输出
