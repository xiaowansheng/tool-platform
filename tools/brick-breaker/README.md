# 霓虹打砖块 (Brick Breaker)

这是一个基于 Canvas 构建的经典霓虹风格打砖块游戏。

## 游戏特性

* **霓虹物理引擎**：基于逻辑像素自适应缩放的物理运动与反弹计算，带球影拖尾。
* **道具丰富**：
  * 🍉 **多球分裂**：使场上的每个球分裂出额外两个球。
  * 📏 **加长挡板**：增加反弹宽度，降低接球难度。
  * 🧲 **磁力挡板**：球撞击挡板后会吸附，按空格或点击重新发射。
  * 🔫 **激光炮台**：按空格或点击屏幕发射激光，直接击碎砖块。
  * 🛡️ **保护护盾**：在游戏底部提供一层保护，球落地时反弹一次。
* **关卡设计**：
  * 第一关：彩虹经典（易）
  * 第二关：空间堡垒（带有坚硬多击砖块，中）
  * 第三关：心动霓虹（复杂心型阵列加移动障碍物，难）
  * 第四关：天崩地裂（会引爆的红色炸弹砖块与急速下落，极难）
* **Web Audio 音乐合成器**：使用原生 Web Audio API，无需加载任何音频文件，自动合成多段清脆的碰撞、得分、道具拾取、胜利与失败音效。
* **双操模式**：完美支持鼠标移动跟随、键盘 `A`/`D`/`←`/`→` 控制、触屏手势拖拽。
* **性能优化**：可开关的霓虹粒子特效、轨迹渲染以及辉光滤镜，保证老旧设备流畅运行。
