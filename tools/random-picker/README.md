# Random Picker (随机抽取工具)

随机抽取数字与列表选项工具，支持范围取数、列表去重、历史记录与滚轮动画效果。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | 娱乐工具 (entertainment-tools) |
| 运行环境 | simple |


## 功能特点

1. **随机数抽取**：可设定最大/最小值，选择抽取个数，并支持开启/关闭重复数据及自动对结果进行升序排序。
2. **列表抽取**：通过文本域自定义候选项，也可以加载姓名、活动、抽奖预设，选择抽取的个数，同样支持是否允许重复。
3. **沉浸式音画效果**：抽取时卡片呈现数字/选项随机飞滚的效果，在滚动中伴随清脆的“咔哒”时钟音效，在尘埃落定时播放具有成就感的和弦提示音。
4. **历史存档**：自动记录每次抽取的次数、时间及对应结果，支持一键清空或复制至剪贴板。
