# Minesweeper (经典扫雷)

经典扫雷游戏，支持初级、中级、高级与自定义参数，配备计时器、雷数指示、双击排雷与拟真爆炸音画效果。

## 游戏操作与特色

1. **基本操作**：
   - **鼠标左键单击**：翻开未知单元格。
   - **鼠标右键单击**：切换插旗，标记可能为地雷的位置。
   - **数字单元格双击 (Chord Click)**：当周围插旗数量刚好等于单元格内的数值时，双击可直接翻开周围其它所有未翻开的格子，加快排雷速度（若判定失误则有触雷风险）。

2. **专业扫雷体验**：
   - **首雷保命（First-click Safety）**：首次左键点击的单元格及其 8 邻域绝不可能生成地雷，确保绝对不会第一步“出师未捷身先死”，且首击必定翻开一片空旷区域。
   - **智能空域延展 (Flood Fill)**：点击到 0 雷区时，自动呈链式递归发散扩展，快速铺开空白格局。

3. **合成音效反馈**：
   - 翻开单元格的轻响、插旗小调。
   - 空域链式展开的流水气泡音。
   - 触雷失败的模拟白噪音低通滤波爆炸轰鸣音。
   - 获胜时的欢快大调琶音。
