# Canvas Playground

在 iframe 沙箱中编写 Canvas 2D 绘图代码，实时查看渲染效果与性能帧率。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | design-tools |
| 运行环境 | sandbox |

## 目录结构

```
canvas-playground/
├── manifest.ts        # 工具元声明
├── app.tsx             # 工具 UI 组件
```
