# 黑白棋 (Reversi / Othello)

这是一个高品质的经典黑白棋（奥赛罗）棋盘策略游戏。

## 游戏特性

* **3D 棋子翻转**：棋子翻面时带有三维旋转（CSS 3D Transform）的顺滑动画，极具解压感。
* **智能 AI 对战**：
  * **新手**：使用贪心策略，追求单步吃子最多。
  * **棋手（中级）**：使用经典的 Minimax 极小化极大算法并结合 Alpha-Beta 剪枝与棋盘格权重表（角落点最高权、边缘高权、边缘临角负权等），具备较强的策略挑战性。
* **落子提示与预测**：智能显示当前玩家所有合法落子点，鼠标悬停时可预览吃子后的棋盘翻转路线。
* **拟真敲击音效**：通过原生 Web Audio API 合成，每次落子有清脆的石子/木纹碰撞音效，多子同时翻转时伴随连绵的翻转声。
* **棋盘占比分析**：带有动感的双方棋子数量对比条，实时计算棋盘占有率。
* **精美主题**：提供赛博蓝紫、经典绿洲、落日余晖、深海幽谷等多种棋盘底色主题。
