# Regex WASM Engine

基于 WASM 编译的高性能正则表达式引擎，支持大型文本匹配与 JS/WASM 性能基准对比。

## 概述

| 属性 | 值 |
|------|-----|
| 分类 | text-tools |
| 运行环境 | wasm |
